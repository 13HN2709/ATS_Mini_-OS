# Optionale Module

Geplante, separat gehaltene Funktionen:

- `spectrum/` – Spectrum Scanner und Peak-Daten
- `dual_rx/` – nur bei bestätigter Hardwareunterstützung
- `web_control/` – Weboberfläche und Verbindungsmodi

Die einzelnen Modulverzeichnisse werden mit eigenen README-Dateien angelegt. Noch kein ausführbarer Code.
