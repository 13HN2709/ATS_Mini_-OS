# ATS Mini OS – Layout-Test für Schriften

**Zweck:** Separater, risikoarmer Bildschirm zum Prüfen von Schriftstilen und internationalen Zeichen vor dem ersten Firmware-Build.

## Geplante Ansicht

- Oben: `FONT LAB` und ausgewählte Schriftfamilie.
- Große Hauptzeile: Frequenzmuster `107.90` und `MHz` im Digital-Segment-Stil.
- Zwei kompakte Textfelder: Retro-Pixel und Terminalschrift.
- Unterer Bereich: Testzeilen für Deutsch, Italienisch, Französisch, Spanisch, Portugiesisch, Polnisch/Tschechisch, Türkisch, Griechisch und Kyrillisch.
- Eigener, rechtsbündiger Bereich für arabische Schrift und gemischten Text mit Zahlen.
- Deutliche Markierung für fehlende Zeichen oder fehlerhafte Schreibrichtung.

## Geplante Bedienung

- Mit dem Encoder zwischen Schriftkandidaten wechseln.
- Eine Testseite für lateinische/griechische/kyrillische Zeichen und eine eigene arabische Testseite.
- Die vorhandenen Radio-Layouts bleiben unberührt; der Test ist ein separates Layout.
- Keine Netzwerkverbindung erforderlich, um die Schrift-Testseiten anzuzeigen.

## Status

Dies ist zunächst eine Layout- und Abnahmespezifikation. Der eigentliche Code wird erst nach Prüfung der Display- und Eingabetreiber sowie der verfügbaren Speicherressourcen ergänzt. Kein Build wurde gestartet.
