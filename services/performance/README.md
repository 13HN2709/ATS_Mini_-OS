# Performance Manager

Planungsplatzhalter für zentral verwaltete CPU-Leistungsprofile.

Anforderungen: CPU-Takt in den Einstellungen auswählbar; rechenintensive Ansichten wie Waterfall können maximale Leistung anfordern; beim Verlassen wird das vorherige Profil wiederhergestellt. Frequenzwerte und Umsetzung bleiben offen, bis Plattform und Framework geprüft wurden.
